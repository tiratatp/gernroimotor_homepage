# เกินร้อยมอเตอร์ — เว็บไซต์หน้าร้าน

เว็บไซต์หน้าร้าน 1 หน้า ภาษาไทย สำหรับ Google Maps และโฆษณา โฮสต์ฟรีบน GitHub Pages

**กฎทอง: แก้ทุกอย่างผ่านเว็บไซต์ GitHub (github.com) ไม่ต้องติดตั้งโปรแกรมอะไรเลย**
Golden rule: edit everything through the GitHub website — no software to install.

ไฟล์ซอร์สโค้ดที่แก้ไขได้มี 3 ไฟล์ (และอัปโหลด/เปลี่ยนไฟล์รูปภาพ JPG/PNG ในโฟลเดอร์ `images/`):
- **`variables.txt`** — ข้อมูลร้านที่ใช้ซ้ำหลายที่ (ชื่อร้าน เบอร์โทร ที่อยู่ LINE Facebook TikTok โดเมน)
- **`template.html`** — ข้อความและโครงสร้างรูปภาพบนหน้าเว็บ
- **`style.css`** — สีของเว็บ (แก้เฉพาะส่วน CHANGE COLORS HERE ต้นไฟล์)

ระบบ GitHub สร้าง `index.html` (หน้าเว็บจริง) `robots.txt` และ `sitemap.xml` ให้อัตโนมัติทุกครั้งที่กด Commit

## ① เปลี่ยนข้อมูลร้าน (ชื่อ/เบอร์โทร/ที่อยู่/LINE/Facebook/TikTok/โดเมน)

1. เปิด `variables.txt` บน GitHub → คลิกปุ่มดินสอ (Edit)
2. แก้เฉพาะ **ข้อความทางขวาของเครื่องหมาย `=`** เท่านั้น → กด **Commit changes**

> **ห้ามแตะชื่อทางซ้ายของ `=`** — ถ้าลบ/เปลี่ยนชื่อตัวแปร หรือพิมพ์รูปแบบผิด ระบบจะไม่สร้างเว็บให้

```
ก่อนแก้:  PHONE_DISPLAY = 02-000-0000
หลังแก้:  PHONE_DISPLAY = 089-123-4567
```

| ชื่อตัวแปร | คืออะไร | รูปแบบที่ถูกต้อง |
|-----------|--------|------------------|
| `SHOP_NAME` | ชื่อร้าน | ข้อความทั่วไป |
| `PHONE_DISPLAY` | เบอร์โทร (แสดงบนเว็บ) | `0XX-XXX-XXXX` เช่น 089-123-4567 |
| `PHONE_TEL` | เบอร์โทร (ปุ่มกดโทร) | ตัวเลข 10 หลักขึ้นต้นด้วย 0 ไม่มีขีด เช่น 0891234567 |
| `PHONE_TEL_INTL` | เบอร์โทรแบบสากล (ข้อมูล Google) | `+66` ตามด้วยเลข 9 หลัก เช่น +66891234567 |
| `PHONE_BACKUP_DISPLAY` | เบอร์สำรอง (แสดงบนเว็บ) | `0XX-XXX-XXXX` |
| `PHONE_BACKUP_TEL` | เบอร์สำรอง (ปุ่มกดโทร) | ตัวเลข 10 หลัก ไม่มีขีด |
| `ADDRESS` | ที่อยู่ (เลขที่ ถนน แขวง เขต) | ข้อความทั่วไป |
| `POSTAL_CODE` | รหัสไปรษณีย์ | ตัวเลข 5 หลัก เช่น 10230 |
| `LINE_ID` | LINE ID | อังกฤษ/ตัวเลข/`.`/`_`/`-` เท่านั้น ห้ามใส่ `@` หรือ URL (ขับเคลื่อนลิงก์ของปุ่ม LINE ทุกปุ่มอัตโนมัติ) |
| `FACEBOOK_PAGE` | ชื่อเพจ Facebook (ท้ายลิงก์) | เช่นเดียวกัน — ใส่เฉพาะ `ชื่อเพจ` ไม่ใส่ facebook.com/... |
| `TIKTOK_USER` | ชื่อบัญชี TikTok | เช่นเดียวกัน เช่น `100motor.bkk` |
| `SITE_URL` | โดเมนจริงของเว็บ | ขึ้นต้น `https://` ลงท้าย `/` เช่น `https://www.yourshop.com/` (หากไม่มีโดเมนตัวเอง ต้องให้ตรงกับ URL ของ GitHub Pages คือ `https://<username>.github.io/<repo>/`) |
| `MAPS_EMBED_URL` | URL ฝังแผนที่จาก Google Maps | ขึ้นต้นด้วย `https://www.google.com/maps/embed?pb=` — วิธี: Google Maps → ค้นหาที่อยู่ → "แชร์" → "ฝังแผนที่" → คัดลอกเฉพาะ URL ใน `src="..."` |
| `BUSINESS_PROFILE_URL` | URL Google Business Profile (ข้อมูล Google/structured data — ไม่แสดงบนหน้าเว็บ) | ขึ้นต้นด้วย `https://` เช่น `https://maps.app.goo.gl/...` — ลิงก์สั้นจาก Google Maps |

ตำแหน่งบนเว็บ: ปุ่ม LINE (โลโก้ `images/line-logo.svg` + ข้อความ) อยู่ในส่วน hero และท้ายทุกส่วนของหน้าเว็บ (ยกเว้นส่วนติดต่อที่มีการ์ด LINE ของตัวเอง) ลิงก์ตรงไปที่ LINE ID ของร้าน ส่วนช่องทางติดต่อเต็ม (เบอร์โทรหลัก เบอร์สำรอง LINE และปุ่มนำทาง) อยู่ในส่วน **“ที่ตั้งและติดต่อเรา”** (`#contact`) พร้อมแผนที่ (URL ฝังจาก `MAPS_EMBED_URL`) ที่อยู่ เวลาเปิด ส่วน Facebook กับ TikTok เป็นการ์ดช่องทางติดต่ออยู่ในส่วน `#contact` เดียวกัน (แถบล่างสุดเหลือเฉพาะข้อความลิขสิทธิ์)

## ② เปลี่ยนข้อความ / รูปภาพ / สี

**ข้อความ:** เปิด `template.html` → ค้นหา `EDIT ME` (หรือ `แก้ไขตรงนี้`) → แก้ข้อความ → Commit

> **สำคัญสำหรับส่วนคำถาม (FAQ):** คำถาม-คำตอบในส่วน FAQ ต้องตรงกับข้อมูล FAQPage JSON-LD ท้ายไฟล์ `template.html` เสมอ — ถ้าเพิ่ม/แก้/ลบคำถาม ให้แก้ทั้งสองที่ให้เหมือนกัน ไม่งั้นระบบจะไม่เผยแพร่เว็บ

**ปุ่มโทรบนแถบบนสุด:** ไอคอนรูปโทรศัพท์ข้างปุ่มเมนู กดแล้วโทรออกทันที ใช้เบอร์จาก `PHONE_TEL` ใน `variables.txt` — เปลี่ยนเบอร์ที่ไฟล์นั้นไฟล์เดียว ปุ่มนี้เปลี่ยนตามเอง

**โครงลิงก์ติดต่อ:** เมนู “ที่ตั้ง/ติดต่อ” ลิงก์ไปส่วน `#contact` ส่วนปุ่ม LINE ใน hero และท้ายทุกส่วน (ยกเว้นส่วนติดต่อ) จะลิงก์ตรงไปยัง LINE ของร้านโดยอัตโนมัติตาม `LINE_ID` ใน `variables.txt`

**รูปภาพ:**
1. เตรียมรูป **JPG หรือ PNG เท่านั้น** ไม่เกิน **5 MB** (ถ่ายมือถือก็ได้ ระบบย่อให้เองตอนเผยแพร่)
2. GitHub → **Add file → Upload files** → อัปโหลดเข้าโฟลเดอร์ `images/` (เช่น `images/shop-front.jpg`)
3. เปิด `template.html` → ค้นหา `SWAP IMAGE` (หรือ `เปลี่ยนรูปตรงนี้`) → เปลี่ยนเป็น `images/ชื่อรูป.jpg` → Commit
   (รูปแรกสุดของหน้า รูปสไลด์ส่งมอบรถ และรูปแชร์ Facebook/LINE แก้ที่ `template.html` ทั้งหมด — ค้นหา `SWAP IMAGE` ได้ทุกรูป)

> **ปุ่ม LINE — แก้ได้เฉพาะข้อความ:** ปุ่ม LINE แต่ละปุ่มสร้างจากโลโก้ LINE (`images/line-logo.svg`) กับข้อความ จึงตั้งข้อความให้ต่างกันได้ในแต่ละส่วน วิธีแก้: เปิด `template.html` หาคำว่า `EDIT ME` ที่อยู่เหนือปุ่ม แล้วแก้เฉพาะข้อความใน `<span class="line-cta-text">...</span>` เท่านั้น
>
> **ห้ามแก้:** ไฟล์โลโก้ `images/line-logo.svg` ลิงก์ของปุ่ม และสีเขียว `#06C755` — ทั้งหมดเป็นข้อกำหนดแบรนด์ของ LINE
>
> ข้อความของแต่ละปุ่ม **ต้องไม่ซ้ำกัน** ถ้าซ้ำ ระบบจะไม่เผยแพร่เว็บ

**สีเว็บ:** เปิด `style.css` → ส่วน `CHANGE COLORS HERE` ต้นไฟล์ → เปลี่ยนค่าสีโทนต่างๆ ได้ตามต้องการ ยกเว้น `--color-primary` ซึ่งถูกกำหนดให้เป็น `#CF0000` (สีแดง) เพื่อให้ตรงตามโลโก้ร้าน การเปลี่ยนค่า `--color-primary` จะต้องเปลี่ยนไฟล์โลโก้และปรับธีมพร้อมชุดทดสอบ ซึ่งเป็นงานของนักพัฒนา → กด Commit เพื่อบันทึก

## ③ เพิ่มหรือลบ การ์ด/รูป/คำถาม/รีวิว/ยี่ห้อรถ

**เพิ่ม:** ค้นหา `COPY FROM HERE` (หรือ `คัดลอกตั้งแต่ตรงนี้`) → คัดลอกทั้งบล็อกถึงบรรทัด `TO HERE` → วางต่อจากบล็อกเดิม → แก้ข้อความ → Commit

**ลบ:** ลบทั้งบล็อกตั้งแต่บรรทัด `COPY FROM HERE` ถึงบรรทัด `TO HERE` (รวม 2 บรรทัดนั้นด้วย) → Commit

ใช้ได้กับ: การ์ดบริการ, รีวิวลูกค้าและรูปสไลด์ส่งมอบรถ (อยู่ในส่วน “ครอบครัวเกินร้อย” เดียวกัน), คำถาม FAQ, ช่องทางติดต่อใน `#contact` (โทรศัพท์/LINE/Facebook/TikTok) และตัวอย่างยี่ห้อ/รุ่นรถ (`<li class="chip">`)

**รีวิวลูกค้า:** ในแต่ละบล็อกให้แก้ 3 จุดตามคำว่า `EDIT ME` ได้แก่ ข้อความรีวิว ชื่อที่แสดง และแหล่งที่มา (`Facebook` หรือ `Google Maps`) คัดลอกข้อความรีวิวตามต้นฉบับโดยไม่แก้คำ และใช้ชื่อแหล่งที่มาเป็นข้อความธรรมดา — ไม่ต้องใส่ลิงก์ ดาว คะแนน หรือวันที่

## ④ หลังกด Commit เกิดอะไรขึ้น

GitHub Actions ทำงานอัตโนมัติ: ทดสอบข้อมูล → สร้างเว็บ → ตรวจ HTML และรูป → ย่อไฟล์ → เผยแพร่

- **✓ เขียว** = เว็บอัปเดตภายใน 1-2 นาที
- **✗ แดง** = พบข้อผิดพลาด — เว็บเดิมยังออนไลน์ปกติ ไม่มีอะไรพัง

## ⑤ ถ้ามี X แดง (เว็บไม่อัปเดต)

เปิดแท็บ **Actions** → คลิกรันที่มี X แดง → ดูว่า step ไหน fail:

| Step ที่ fail | สาเหตุ | วิธีแก้ |
|--------------|--------|---------|
| Run safety tests | FAQ หน้าเว็บไม่ตรงกับ JSON-LD ท้ายไฟล์ / อ้างรูปที่ไม่มีใน `images/` / ลิงก์แผนที่ไม่ตรงกับ JSON-LD | อ่าน log แล้วแก้จุดที่ระบุ (ดูข้อ ②) |
| Check SITE_URL is not 404 | URL ใน `SITE_URL` ตอบกลับ 404 หรือตรวจสอบ URL ไม่สำเร็จ | ตรวจว่า `SITE_URL` เปิดได้จริงและตรงกับ `https://<username>.github.io/<repo>/` หรือโดเมน CNAME แล้ว Commit ใหม่ |
| Build website | `variables.txt` ผิดรูปแบบ (log เป็นภาษาไทย) | แก้ตามตารางข้อ ① |
| Validate HTML | แท็กใน `template.html` ขาดหรือเสีย | ยกเลิกการแก้ไขครั้งล่าสุด (revert) |
| Check ... | ลบคำว่า `EDIT ME` / เครื่องหมายคัดลอก / ลิงก์ `style.css` ออกโดยไม่ตั้งใจ | คืนค่าส่วนที่ลบกลับมา |
| Check image files | รูปไม่ใช่ JPG/PNG (เช่น HEIC จาก iPhone) หรือเกิน 5 MB | ลบไฟล์นั้น → แปลง/ย่อรูป → อัปโหลดใหม่ |

**ทางออกสุดท้าย:** ส่ง repo ทั้งหมดพร้อม README นี้ให้นักพัฒนาหรือ AI agent ช่วยแก้

## ⑥ ไฟล์ที่ห้ามแตะ

- **`index.html`**, **`robots.txt`**, **`sitemap.xml`** — ระบบสร้างอัตโนมัติ แก้แล้วถูกเขียนทับ
- **`build.py`**, **`.github/`**, **`.htmlvalidate.json`** — ระบบสร้างและตรวจสอบเว็บ ห้ามแก้

ไฟล์ที่ขึ้นเว็บจริงมีเฉพาะ `index.html`, `style.css`, `robots.txt`, `sitemap.xml`, `images/` และ `CNAME` (ถ้ามี) — ไฟล์ต้นฉบับอื่นไม่ถูกเผยแพร่

## ⑦ ติดตั้งครั้งแรก + โดเมนของร้านเอง

**ติดตั้งครั้งแรก (ทำครั้งเดียว):**
1. ส่งไฟล์ทั้งหมดขึ้น branch `main` ของ GitHub repo
2. **Settings → Pages → Source** เลือก **GitHub Actions** (ห้ามเลือก "Deploy from branch")
3. รอ ✓ เขียวครั้งแรก — เว็บจะอยู่ที่ `https://<username>.github.io/<repo>/`

**ใช้โดเมนของร้านเอง:**
1. ตั้ง `SITE_URL` ใน `variables.txt` เป็นโดเมนจริง (เช่น `https://www.yourshop.com/`)
2. สร้างไฟล์ชื่อ `CNAME` (ไม่มีนามสกุล) ใส่โดเมนจริงบรรทัดเดียว เช่น `www.yourshop.com` — ห้ามใส่โดเมนจำลอง
3. ตั้ง DNS ที่ผู้ให้บริการโดเมน:
   - โดเมนหลัก (`yourshop.com`): A record `@` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - www: CNAME `www` → `<username>.github.io`
4. **Settings → Pages** → ใส่ Custom domain → Save → รอ DNS แพร่ (ไม่กี่นาทีถึงหลายชั่วโมง) → ติ๊ก **Enforce HTTPS**

## ⑧ เช็กลิสต์ก่อนเปิดใช้จริง (ตรวจด้วยมือเท่านั้น)

- [ ] ยี่ห้อ/รุ่นรถในส่วน "ยี่ห้อและรุ่นรถ" ตรงกับสต็อกจริงที่ร้าน
- [ ] เปิดเว็บบนมือถือ กดเมนู “ที่ตั้ง/ติดต่อ” ว่าเลื่อนไปส่วน `#contact` ถูกต้อง
- [ ] กดทดสอบปุ่ม LINE ใน hero และท้ายแต่ละส่วนว่าเปิดแอป/เว็บ LINE ไปยัง `@{{LINE_ID}}` ถูกต้อง และข้อความบนปุ่มแต่ละส่วนถูกต้อง
- [ ] ในส่วน “ที่ตั้งและติดต่อเรา” กดทดสอบ: แผนที่ (แสดงที่ตั้งร้านถูกต้อง), นำทาง (เปิด Google Maps), เบอร์หลัก, เบอร์สำรอง (เปิดหน้าโทรศัพท์) และ LINE
- [ ] ในส่วนติดต่อ กดทดสอบลิงก์ Facebook และ TikTok
- [ ] โทรเข้าเบอร์ที่แสดงบนเว็บจริง ๆ ว่าติด
- [ ] ส่ง URL เข้า Google Search Console (search.google.com/search-console)
- [ ] ใส่ URL เว็บใน Google Business Profile (business.google.com)
